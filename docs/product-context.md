# Demand Radar

## Overview

Demand Radar es una plataforma SaaS para detectar señales de demanda e intención de compra desde fuentes públicas.

## Verticales iniciales

- Autos usados
- Bienes raíces
- Smartphones
- Laptops/Desktop

## Objetivo MVP

- detectar intención de compra
- mostrar señales
- enviar alertas

## Roadmap futuro

- Tender Monitor para licitaciones públicas Honduras
- reutilizando collectors + alerts + enrichment
